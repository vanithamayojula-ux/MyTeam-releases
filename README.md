# MyTeam — Windows downloads

Installers for **MyTeam**, a desktop app for browsing 267 specialist AI agents and installing them into Claude Code, Cursor, Codex and 8 other coding tools.

**Download:** https://myteamhq.vercel.app/#/download — or pick a file from [Releases](../../releases/latest):

| File | For |
|---|---|
| `MyTeam-Setup-x64.exe` | Most Windows 10 and 11 PCs |
| `MyTeam-Setup-arm64.exe` | Windows on ARM devices |

The installers are not code-signed yet, so on first run Windows SmartScreen shows **"Windows protected your PC"** — click **More info → Run anyway**.

This repository only hosts release files. MyTeam is based on [Agency Agents](https://github.com/msitarzewski/agency-agents-app) by Michael Sitarzewski, used under the MIT license (see [LICENSE](LICENSE)); agent personas come from [agency-agents](https://github.com/msitarzewski/agency-agents).
